# SpeedRead

Веб-приложение для скорочтения методом RSVP (Rapid Serial Visual Presentation).

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Публикация на GitHub Pages

1. Включите GitHub Pages в настройках репозитория (Source: GitHub Actions).
2. Workflow будет добавлен позже.

## Стек

- React + TypeScript + Vite
- IndexedDB (планируется)
- PDF.js, Mammoth.js, JSZip для импорта
